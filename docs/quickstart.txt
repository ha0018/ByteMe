ByteMe 局域网文件传输工具

1. 将压缩包完整解压，在两台同一局域网的 Windows 电脑上运行 ByteMe.exe。
2. 缺少 MSVC 运行库时，先安装随包附带的 vc_redist.x64.exe。
3. Windows 防火墙提示时允许访问专用网络。
4. 选择“附近设备”中的接收方，点击“发送文件”，也可拖入文件。
5. 接收方确认接收；文件完成后会自动校验并保存到设置的目录。
6. 中断后在发送方选择原任务，点击“继续”；接收方保留临时文件供续传。

默认端口：TCP 45455 / UDP 45454。
设备发现失败时，可以用“输入 IP”手动填写接收方 IPv4 地址与 TCP 端口。
本程序使用自己的通信协议，与飞鸽传书不互通。

本机双实例示例（使用不同 TCP 端口）：
ByteMe.exe --name A --port 45455 --settings-dir config-a
ByteMe.exe --name B --port 45456 --settings-dir config-b
在 A 中手动添加 127.0.0.1:45456，然后发送文件。

完整源码、构建说明和设计文档位于 ByteMe 工程目录。
